# 写真撮影 × 英語学習アプリ

写真を起点に、探究型の英語学習を行うためのポートフォリオ用プロトタイプです。

ユーザーが選択または撮影した写真からキーワードを抽出し、そのキーワードをもとに Gemini が英語で問いかけます。対話の内容から短い英語ストーリーとクイズを生成し、最後に学習内容を振り返るカードを作成できます。

## 制作背景

このアプリでは、英語を単なる暗記対象として扱うのではなく、写真や身近なテーマをきっかけに「考えるための道具」として使う学習体験を目指しました。

企画段階では、写真撮影、Google Vision による認識情報の提示、単語選択、英語での会話、会話からの記事生成、問題演習、コイン獲得、学習の振り返り、保存済みテーマからの復習という流れを設計しました。身近な写真から始めることで、学習者が自分の興味に近いテーマで英語に触れられるようにしています。

また、1 回の会話で終わるのではなく、生成された記事やクイズを通して内容を確認し、最後にまとめカードを作ることで、英語表現だけでなく「何を考えたか」「何を学んだか」まで残せる構成にしました。

## 学習フロー

1. 英語レベルを選択する
2. 写真を選択、または Web カメラで撮影する
3. Google Vision API が写真内の要素を認識する
4. 認識結果から学習に使うキーワードを選ぶ
5. Gemini と英語で会話する
6. 会話内容をもとに英語記事を生成する
7. 記事に基づくクイズに回答する
8. コイン獲得や正誤判定を確認する
9. 学習内容をまとめカードとして保存する
10. 保存済みテーマから復習、または別キーワードで再学習する

## 目的

このプロトタイプは、写真を起点にした探究型英語学習の流れを、実際に動くアプリとして検証するために作成しました。

主な狙いは以下です。

- 写真を入口にした探究型の英語対話を試す
- 学年や CEFR レベルに応じた問いかけを生成する
- 対話からストーリー、クイズ、振り返りへつなげる
- 学習テーマと結果を保存し、あとから復習できるようにする
- AI API を使った学習フローの実装可能性を確認する

## 実装上の工夫

- 写真から抽出したラベルをそのまま使うのではなく、学習の入口になるキーワードとして選べるようにしました。
- 学年や CEFR レベルに応じて、AI の問いかけや選択肢の出し方を変えています。
- クイズは 1 問ずつ API を呼ぶのではなく、複数問をまとめて生成することで API 呼び出し回数を抑えています。
- 対話だけで終わらせず、ストーリー、クイズ、振り返りカードへ進む学習フローを作りました。
- 保存済みテーマから復習したり、同じ写真の別キーワードで再開したりできるようにしています。
- 学習済みの単語は復習用として扱い、新しい単語で再開しやすいようにしています。
- API 処理は別スレッドで実行し、待機中もアプリの状態が分かるようにしています。

## 主な機能

- 画像ファイルの選択、または Web カメラでの撮影
- Google Cloud Vision API による画像ラベル抽出
- 抽出したキーワードをもとにした Gemini との英語対話
- 学年・英語レベルに応じた選択肢や問いかけの調整
- 対話内容をもとにした英語ストーリー生成
- ストーリーに基づくクイズ生成と採点
- コイン獲得、学習レベルの簡易調整
- 学習テーマ、ストーリー、クイズ結果、振り返りカードの保存
- 保存済みテーマからの復習、または別キーワードでの再開

## セットアップ

必要な Python パッケージをインストールします。

```bash
pip install pillow opencv-python google-generativeai google-cloud-vision
```

Gemini API キーを環境変数に設定します。

```bash
set GEMINI_API_KEY=your_api_key
```

Google Cloud Vision API を使う場合は、サービスアカウント JSON のパスを設定します。

```bash
set GOOGLE_APPLICATION_CREDENTIALS=service_account_key.json
```

モデル名を変更したい場合は、任意で `GEMINI_MODEL_NAME` を設定できます。

```bash
set GEMINI_MODEL_NAME=models/gemini-2.5-flash
```

## 実行方法

```bash
python inquiry_app_prototype.py
```

簡単な Gemini 接続確認には、以下を実行します。

```bash
python quick_test.py
```

## ファイル構成

- `inquiry_app_prototype.py`: アプリ本体
- `config.py`: 環境変数をもとにした設定値
- `prompt_master.txt`: 対話全体を制御するプロンプト
- `prompt_content.txt`: ストーリー生成用プロンプト
- `prompt_quiz.txt`: クイズ生成用プロンプト
- `prompt_tag.txt`: 次に探究するキーワード候補の生成用プロンプト
- `prompt_mission.txt`: 次の写真ミッション候補の生成用プロンプト
- `profile.json`: 学習履歴、テーマ、クイズ結果などの保存先

## 注意点

このリポジトリはポートフォリオ用の PoC プロトタイプです。本番運用を前提にしたセキュリティ、エラーハンドリング、UI 設計、データ保存方式にはまだ改善余地があります。

API キーやサービスアカウント JSON などの秘密情報は Git 管理しないでください。`service_account_key.json`、`taigakey.txt`、`profile.json` は `.gitignore` に含めています。

`profile.json` には画像データを含む学習履歴が保存されるため、利用を重ねるとファイルサイズが大きくなる可能性があります。
